# 💻 Desenvolvedora Back-End | Aberta para Estágio e Júnior

Olá! Sou desenvolvedora Back-End focada em Python e gosto de construir soluções que resolvam problemas reais. Recentemente, mergulhei no universo SaaS, desenvolvendo uma plataforma completa onde pude aplicar tudo o que acredito em termos de código limpo e escalabilidade.

Minha base técnica é em **FastAPI e Django**, mas minha visão vai além das linhas de código: cuido desde a modelagem do banco de dados até o deploy em nuvem. Como também navego bem pelo Front-End, consigo garantir que a integração entre o servidor e a interface seja eficiente e segura.

### 🚀 O que trago na minha bagagem:
- **Desenvolvimento SaaS:** Foco em arquitetura de APIs modernas e escaláveis.
- **Segurança e Qualidade:** Implementação de JWT para autenticação e testes unitários com Pytest.
- **Tecnologias:** Domínio de PostgreSQL, Git/GitHub e automação com CI/CD.
- **Inovação:** Integração de funcionalidades com IA Generativa.

Estou em busca da minha primeira oportunidade como Desenvolvedora Júnior ou Estagiária. Se você busca alguém que coloca a mão na massa com propósito, vamos trocar uma ideia!
